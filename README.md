# 跨境实战

Shopee 与 TikTok Shop 电商运营知识库。首页提供按平台浏览、全文搜索、收藏和学习进度。虾皮竞价教程包含七步流程、可勾选检查表、同款核验和竞价计算器。

## 本地运行

在仓库根目录运行 Python 静态服务。

```sh
python3 -m http.server 8000
```

在浏览器访问 `http://localhost:8000/`。站点使用原生 HTML、CSS 和 JavaScript，无需安装包或构建。

## 编辑和发布教程

1. 打开右上角的 **内容管理**。使用 **新建教程** 或已有教程旁的 **编辑**，填写平台、分类、阅读时长和正文。
2. 切换到 **预览**，确认检查表、步骤、图片和表格显示正常，再保存教程。新建时可指定网址标识。保存后网址标识固定，供收藏和深链接使用。
3. 在 **内容管理** 点击 **导出 JSON**，保留一份备份，用导出的 `tutorials.json` 替换仓库中的 `content/tutorials.json`。
4. 将更新提交到站点的发布分支。使用 GitHub Pages 时，发布源选该分支的根目录。在无痕窗口检查教程库和新教程路径。

编辑、收藏、学习进度和计算器参数保存在当前浏览器。导出的文件包含教程库内容。换浏览器或设备编辑时，可通过 **导入 JSON** 载入备份。发布版更新后，本地草稿仍会覆盖同一篇教程。确认备份后，可以使用 **恢复站点发布版** 清除本地内容修改并重新阅读发布版。

## 教程正文格式

正文支持常用的 Markdown 段落、标题、列表、表格、链接、图片及代码块。`##` 标题会加入目录。也可以从编辑器工具栏插入交互区块。

```markdown
## 报名前检查

:::checklist 价格和库存
- 已核算采购成本与平台费用。
- 已核对实际可售库存。
:::

## 操作步骤

:::steps
### 确认资格

打开卖家中心检查店铺与商品的活动资格。

### 填写报价

:::warning 校验成本
打开 [竞价计算器](#/calculator)，确认拟出价时的预计利润。
:::
:::
```

图片可放入仓库的 `content/images/` 目录。用 `![截图说明](content/images/entry.png)` 引用，或填写可访问的 HTTPS 图片地址。发布时请一并提交图片文件。

也可以直接维护 `content/tutorials.json`。保留根对象的 `version: 1` 和 `tutorials` 数组，复制现有教程对象并更改各字段。`id` 在库内唯一，使用小写英文字母、数字与连字符。`platform` 支持 `shopee`、`tiktok`、`general`。新教程的 `cover` 可从编辑器提供的封面中选择。
